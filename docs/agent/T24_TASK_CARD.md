## User Story

As a **DOCTOR**, I need to export a patient's clinical summary as a PDF file so that I can include it in referral letters and maintain offline clinical records.

---

## Scope

### 1. PDF Generation Service
- **File:** `backend/app/services/pdf_report.py`
- Function: `generate_patient_summary_pdf(patient_id, summary_data: dict) -> bytes`
- Uses `reportlab` library
- Sections: Vitals, Metabolic Score, Medications, Symptoms, Nutrition, Active Care Plans
- Header: "MetoCare Clinical Summary" + patient_id + generated_at
- Footer: "Generated by MetoCare — Confidential"

### 2. Route
- **File:** `backend/app/api/v1/routes/patients.py` (additive only)
- Endpoint: `GET /patients/{patient_id}/summary.pdf`
- RBAC: DOCTOR (consent-gated), ADMIN (any), PATIENT -> 403, AI_SERVICE -> 403
- Response: `application/pdf` with Content-Disposition attachment

### 3. Tests
- **File:** `backend/tests/api/test_pdf_export_api.py`
- 7 tests covering RBAC, PDF header, Content-Disposition
